### Sobre este modulo
En este modulo estaremos hablando sobre los conceptos fundamentales a comprender a la hora de trabajar con contenedores. Conoceremos como instalar docker en linux, hablaremos sobre la importancia de conocer los conceptos de computador, maquina virtual y contenedor a la hora de desarrollar software.
Por ultimo nos pondremos manos a la obra trabajando con contenedores para ello tendremos que conocer conceptos como dockerfile o docker image.
