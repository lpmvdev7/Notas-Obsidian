### ¿Que es el montaje de volumenes en docker?
El montaje de volúmenes en docker es una manera de mapear un folder o archivo desde el sistema operativo host hacia un folder o archivo dentro del contenedor.
Esto permite la persistencia de datos afuera del contenedor incluso cuando el contenedor es eliminado, esta característica es tan potente que permite que múltiples contenedores compartan el mismo volumen, haciendo que el compartir datos entre contenedores sea facil.
