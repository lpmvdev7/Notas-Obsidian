### ¿Que es docker compose?
Docker compose es la herramienta predeterminada de docker para correr aplicaciones multicontenedor, es decir contenedores que funcionan juntos.
Para ello docker compose utiliza un archivo con terminación YAML, dentro de este archivo describimos nuestro software mediante servicios, redes y volúmenes, esto nos provee de una forma sencilla de administrar aplicaciones multicontenedor con un simple comando.
