### ¿Que es Docker?
Docker es una tecnología de contenedores que nace en base a una problemática muy común a la hora de desplegar proyectos de software, **Funcionaba en mi maquina**, esta frase representa la problemática que docker resuelve.
Supongamos que estamos desarrollando un Sistema de citas para una clínica dental, en el mundo del desarrollo moderno es común con trabajar con software de otros, a esto se le conoce como dependencias. Dado que el destino final de nuestro sistema es que sea usada en las computadoras de la clínica, tenemos que asegurarnos que este funcione de la misma manera en todas las maquinas, para ello creamos un contenedor de docker.
![](https://www.docker.com/app/uploads/2024/02/docker-default-meta-image.png)
### ¿Que es un contenedor?
Un contenedor es una unidad estandarizada de software que empaqueta por completo todas las dependencias que necesita un software para funcionar, volviendo al ejemplo de la clínica dental, necesitaríamos contenedores para hacer que el sistema funcione de forma estandarizada en todas las maquinas de la clínica.
