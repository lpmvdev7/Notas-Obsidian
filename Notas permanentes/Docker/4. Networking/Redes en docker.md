### ¿Que son las redes en docker?
Como hemos visto antes, docker nos permite desplegar múltiples contenedores ya sea uno por uno, o con un solo comando. En muchas ocasiones estos contenedores necesitan comunicarse entre si, por ejemplo una base de datos con una API y la API con un frontend, es en estas ocasiones en las que necesitaremos de una red.
Las redes en docker nos permiten aislar contenedores que comparten información entre si, creando de esta manera entornos controlados que nos ayudan a mantener la seguridad de nuestras aplicaciones.
