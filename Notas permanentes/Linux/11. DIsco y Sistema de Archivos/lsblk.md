### ¿Que hace el comando?
Comando que nos muestra información relevante sobre los dispositivos en nuestro sistema, este comando es muy usado para ver información como el sistema de archivos utilizado, el porcentaje de uso, el punto de montaje y el nombre del dispositivo.

```bash
#Nos muestra todos los dispositivos de almacenamiento.
lsblk
```

```bash
#Nos muestra todos los dispositivos de almacenamiento junto con los sistemas de archivos que tienen
lsblk -f
```
