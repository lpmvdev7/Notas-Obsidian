### Sobre el comando sort
El comando sort, se encarga de clasificar y ordenar salidas de texto en la terminal de linux, puede ser utilizado para ordenar alfabéticamente archivos de texto.

Si tenemos una archivo con una lista de nombres como el siguiente:
```text
Roberto
Ana
Fernando
Carla
Diego
Beatriz
Ximena
Miguel
Sofia
Luis
Valentina
Jorge
Natalia
Hector
Paola
Emilio
Carmen
Ricardo
Gabriela
Andres
```

Con el comando sort podemos ordenarlos alfabéticamente.
```bash
sort nombres.txt
```

Así quedaría nuestro archivo
```text
Ana
Andres
Beatriz
Carla
Carmen
Diego
Emilio
Fernando
Gabriela
Hector
Jorge
Luis
Miguel
Natalia
Paola
Ricardo
Roberto
Sofia
Valentina
Ximena
```
