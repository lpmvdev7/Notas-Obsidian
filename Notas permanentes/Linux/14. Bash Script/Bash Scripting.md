### ¿Que es Bash Scripting?
La programación de shell (scripts) automatiza tareas administrativas, operaciones repetitivas y la monitorizacion del sistema en Linux. Bash es el lenguaje de shell y scripts predeterminado en la mayoría de las distribuciones.
![](https://miro.medium.com/v2/resize:fit:1400/1*GugKOJXJTFqpag3HwtdsJw.jpeg)
### ¿Que es un script?
Los scripts se pueden definir como archivos de texto que contienen una serie de instrucciones escritas en un lenguaje de programación como python, javascript o bash, cuyo fin es completar una tarea.
