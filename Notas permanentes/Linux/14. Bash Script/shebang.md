### ¿Que es shebang?
El shebang es la primera linea de un script en Linux, esta le indica al sistema operativo que interprete debe utilizar para ejecutar el archivo.

```bash
#!/bin/bash
```

Cuando el sistema ve esta instrucción interprete que las instrucciones que contiene el archivo deben ser ejecutadas utilizando como interprete bash.

### ¿Que es el interprete?
El interprete es el programa encargado de leer, traducir y ejecutar el código fuente linea por linea en tiempo real.

```bash
#!/usr/bin/python3
```

```bash
#!/usr/bin/node
```

```bash
#!/usr/bin/env python3
```

>Los shebang nos permiten especificar el interprete, debido a esto es posible crear combinaciones especificas usando otros lenguajes de programación como bash, python y node
