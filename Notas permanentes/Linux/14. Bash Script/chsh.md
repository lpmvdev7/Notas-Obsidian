### ¿Que hace el comando?
El comando nos ayuda a cambiar la shell del usuario actual.

### Uso del comando
```bash
# Establecer una shell de forma interactiva
chsh

# Establecer una interprete de comandos especifico
chsh -s /bin/bash

# Establecer una shell para un usuario en especifico
chsh -s /bin/bash pablo
```

comando eval y comando exec
