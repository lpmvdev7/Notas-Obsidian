### ¿Que es la automatización?
La automatización se refiere al proceso de convertir tareas repetitivas en flujos completos que ocurren con la mínima supervision.
El ecosistema linux es especialmente bueno para este tipo de tareas ya que mediante lenguajes de scripting como bash o python podemos tomar una tarea diaria que le puede tomar horas a una persona y convertirla en un programa ejecutable que tan solo lleva 5 minutos.
