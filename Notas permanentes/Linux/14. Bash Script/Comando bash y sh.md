### ¿Que hacen los comandos bash y sh?
Como ya sabemos bash y sh son interpretes de linea de comandos, al usarlos como comandos estamos dándole el poder a un archivo de tipo script que se ejecute como comando incluso si este no tiene permisos de ejecución.

```bash
bash script.sh
```

O ejecutar comandos
```bash
bash -c "ls"
```
