### ¿Que es un comando?
Un comando es una instrucción de texto que se le da al sistema operativo para que ejecute una acción en especifico.
Algunos ejemplos básicos de lo que puedes hacer con comando es:
* Listar el contenido de una carpeta
* Ver el contenido de un archivo de texto
* Mover carpetas de un ubicación a otra
* Eliminar carpetas

Aquí podemos ver un ejemplo sencillo de como se utiliza el comando ls.
```bash
ls
```

En este ejemplo se puede ver el resultado del comando ls, usando -la.
```bash
$ ls -la
total 24
drwxr-xr-x  5 usuario usuario 4096 jul 15 10:00 .
drwxr-xr-x 20 usuario usuario 4096 jul 14 09:30 ..
-rw-r--r--  1 usuario usuario  220 jul 14 09:30 .bashrc
```
### ¿Como ver la información de un comando?
Para ver la información de un comando en linux tenemos dos opciones:
**tldr**: nos muestra ejemplos con las opciones que se pueden aplicar a un comando.
**man**: manual oficial de un comando
