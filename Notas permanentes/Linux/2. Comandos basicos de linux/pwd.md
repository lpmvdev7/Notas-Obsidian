### Print Working Directory
El comando pwd es un comando superutil que nos ayuda como usuarios a ubicarnos dentro de nuestro sistema de archivos.
Con pwd podemos saber exactamente en que lugar del sistema de archivos nos encontramos, lo cual puede ser util para utilizar junto con otros comandos que necesitan rutas como argumentos.

```bash
pwd
/home/pablo
```
