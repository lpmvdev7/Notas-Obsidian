### ¿Cuando utilizamos el comando tree en linux?
El uso del comando tree se da cuando nosotros como usuarios queremos tener una visualización gráfica en la terminal de como es que se organizan los archivos dentro de un directorio especifico.
Esto es realmente útil cuando estamos trabajando en proyectos de código que nosotros no hemos empezado, como en el caso de clonar un repositorio de github, en este caso en tree nos permitiría ver como esta organizado el proyecto y en base a eso ponernos a chambear.

```bash
.
├── src
│   ├── index.html
│   ├── input.css
│   ├── output.css
│   └── script.js
└── tailwind.config.js

2 directories, 5 files
```
