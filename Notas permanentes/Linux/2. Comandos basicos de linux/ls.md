### Para que sirve el comando ls en linux
El comando ls es un comando de Navegacion en linux que cumple la función de listar los archivos y carpetas dentro de un directorio en nuestro sistema de archivos

```bash
pablo@lpmvdev7linux:~$ ls
backup-repos.list          examplemv         package.json  resultadoCSS
Base-de-datos-restaurante  Imágenes          PDF           snap
blender-5.0.1-linux-x64    key-gh.pem        Plantillas    themes
cacafire                   markitdown        Proyectos     Vídeos
Descargas                  Música            pt
Documentos                 Ninebox-new       Público
Escritorio                 nuevo_nombre.txt  restaurante
pablo@lpmvdev7linux:~$
```
