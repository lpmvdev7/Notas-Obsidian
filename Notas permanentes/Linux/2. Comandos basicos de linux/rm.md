### ¿Que hace rm?
El comando rm nos ayuda a eliminar archivos o directorios dependiendo de las opciones que utilicemos en este.

Si queremos eliminar un archivo, lo único que tenemos que hacer es ejecutar rm
```bash
rm archivo.txt
```

Si queremos eliminar un directorio tenemos que tener en cuenta que este puede tener archivos u otros directorios dentro, es por ello que tenemos que utilizar la opcion -r para eliminarlo.
```bash
rm -rf directorio
```
