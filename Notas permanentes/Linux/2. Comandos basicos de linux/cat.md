### Comando cat para ver el contenido de archivos
El comando cat nos ayuda a ver el contenido de los archivos de texto en nuestro sistema. 

```bash
cat tailwind.config.js 
/** @type {import('tailwindcss').Config} */
module.exports = {
  content: ["./src/**/*.{html,js}"],
  theme: {
    extend: {
    },
  },
  plugins: [],
}

```

Si queremos conocer mas sobre el comando cat, podemos ejecutar alguno de los siguientes comandos.
```bash
tldr cat 
man cat
```
