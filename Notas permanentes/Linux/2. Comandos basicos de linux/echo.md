### ¿Que hace el comando echo?
El comando echo es un comando que nos ayuda a escribir un mensaje en la terminal.
La utilidad que mas le he encontrado a este comando es mediante el uso de pipes en linux o para crear archivos a partir de un texto determinado

```bash
echo "Hola mundo"
Hola mundo
```
