### ¿Quien es root?
Root es el nombre por el que se le conoce al superusuario en linux, este usuario es el todopoderoso dentro del sistema operativo, con este usuario nosotros tenemos la capacidad de acceder a información clasificada dentro de nuestro sistema e incluso borrar nuestro sistema.
Por todo lo anterior dicho se recomienda que el usuario de root no sea el usuario principal del sistema ya que dadas sus amplias capacidades puede convertirse en un arma de doble filo.

### Cuando usar root?
Podemos utilizar root en alguna de las siguientes situaciones:
* Cuando queremos instalar software
* Cuando queremos crear usuarios y grupos
* Cuando queremos ver archivos restringidos del sistema
* Cuando queremos ejecutar ciertas tareas que ocupan un nivel elevado de permisos.

### Como usar root?
En linux tenemos dos formas de usar root:
1. Siendo el usuario root, es decir estar logueado como este
2. Mediante el comando sudo
