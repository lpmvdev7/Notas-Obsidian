### ¿Que hace el comando groups?
Este comando es informativo, nos permite ver a que grupos pertenece nuestro usuario y los usuarios que le especifiquemos.

### Uso
```bash
groups 
pablo adm dialout cdrom sudo dip plugdev users lpadmin sambashare ollama docker
```

```bash
groups angel
angel : angel inges
```
