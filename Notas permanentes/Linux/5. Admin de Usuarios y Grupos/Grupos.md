### ¿Que son los grupos en linux?
Un grupo en linux es un conjunto de usuarios, una colección de estos. Los grupos en linux nos ayudan a juntar varios usuarios dadas ciertas características en común que estos comparten entre si, como lo puede ser tareas o responsabilidades similares.

### Los Grupos primarios
Los grupos primarios son aquellos grupos que se le asignan a un usuario de manera automática, estos suelen llevar el nombre del usuario y se asignan automáticamente a cada archivo o directorio que el usuario cree.

### Comandos relacionados a grupos
Los sistemas operativos linux nos brindan varios comandos que pueden ejecutar instrucciones relacionadas a grupos
* groupadd
* groupmod
* groupdel
* groups
* gpasswd

### Archivo /etc/groups
El archivo /etc/groups es el archivo en el que se guardan todos los grupos que existen en el sistema. En este archivo se guarda información como: 
* id del grupo
* nombre del grupo
* miembros del grupo
