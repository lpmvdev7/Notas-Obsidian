## ¿Que es el Sistema Operativo?
El sistema operativo es la pieza de software principal que nos permite interactuar con los dispositivos de hardware como: Teléfonos celulares, computadoras, consolas de videojuegos etc. Siendo el principal responsable de controlar los elementos de hardware que constituyen lo que conocemos como computador siendo estos el almacenamiento, la memoria y la CPU.

### Sistemas operativos mas conocidos
Los sistemas operativos mas conocidos son:
1. Linux
2. MacOs
3. Windows
4. IOS
5. Android

### ¿Como interactua el usuario con el sistema operativo?
El usuario interactua con el sistema operativo mediante dos maneras principalmente:
1. GUI (Graphic User Interface): El usuario interactua con la tecnología mediante la interfaz gráfica, siendo esta compuesto por iconos, ventanas y varios otros elementos visuales que permiten realizar determinadas tareas al usuario.
2. CLI (Comand Line Interface): La interfaz de linea de comandos es una interfaz basada en texto que permite al usuario realizar todas las tareas del sistema mediante el uso de comandos.
