### Introducción
En Linux tenemos dos formas principales de trabajar con archivos, estas son mediante editores de texto, los mas famosos en linux son:
1. Vim
2. Nano

Estos editores de texto son utilizados en ambientes de desarrollo para editar archivos de configuración o incluso para crear scripts que brinden una solución empresarial. Tanto Vim como Nano nos ayudan a editar texto utilizando la linea de comandos, por mi parte estaré utilizando Vim.
