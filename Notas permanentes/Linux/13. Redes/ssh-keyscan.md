### ¿Que hace el comando?
El comando ssh-keyscan es una utilidad de OpenSSH que ayuda a recopilar claves publicas de hosts remotos, para ello imprime en el stdout estas llaves publicas.

```bash
ssh-keyscan 172.18.0.2
```
