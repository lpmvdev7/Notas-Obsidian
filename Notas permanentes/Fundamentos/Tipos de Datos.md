### ¿Que son los tipos de datos?
Los tipos de datos en programación son clasificaciones que nos ayudan a saber que clase de valor se encuentra almacenado en una variable.
Los tipos de datos mas básicos son los siguientes
* Enteros
* Flotantes
* Booleanos
* Strings
### Enteros
A continuación mostrare como usar enteros en los siguientes lenguajes de programación:
* Python
* Javascript
```python
numero = 10
print(type(numero)) #Imprimimos el tipo de la variable numero
```

```javascript
let numero = 10
console.log(typeof(numero))
```

### Flotantes
A continuación mostrare como usar números flotantes en los siguientes lenguajes de programación:
* Python
* Javascript
```python
flotante = 10.5
print(type(flotante)) #Imprimimos el tipo de variable flotante
```

```javascript
let flotante = 10.5
console.log(typeof(flotante))
```

### Booleanos
A continuación mostrare como usar valores booleanos en los siguientes lenguajes de programación:
* Python
* Javascript
```python
es_mayor_edad = True
tiene_cuenta = False

print(type(es_mayor_edad))
print(type(tiene_cuenta))
```

```javascript
let esMayorEdad = True
let tieneCuenta = True

console.log(typeof(esMayorEdad))
console.log(typeof(tieneCuenta))
```
