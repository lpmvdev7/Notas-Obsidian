### ¿Que son los ciclos while?
Los ciclos while son estructuras de control que nos ayudan a ejecutar un bloque de código siempre y cuando se cumpla una condición especifica.

```python
# Ejemplo en python
x = 5

while x > 0:
	x = x - 1
	print(x)
```

```javascript
// Ejemplo en javascript
let x = 5
while(x>0){
	x = x -1
	console.log(x)
}
```
