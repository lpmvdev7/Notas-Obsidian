### ¿Que son los condicionales?
Los condicionales son estructuras de control que nos ayudan en la toma de decisiones durante el flujo de un programa. Mediante el uso de condicionales el flujo de nuestro programa puedo tomar una dirección u otra dependiendo de parámetros que nosotros controlamos.
La estructura de control condicional mas utilizada en todo el mundo son los ciclos if.

### Ejemplo de condicionales
Supongamos que tenemos una sitio web que vende productos alcohólicos, queremos prevenir que personas menores de edad entren al sitio web y puedan comprar nuestro producto, para estos casos usaremos un condicional.
```python
# Tienda de licores
edad_usuario = int("Cual es tu edad")
if edad_usuario >= 18:
	print("El usuario es mayor de edad puede entrar...")
else:
	print("El usaurio no puede entrar al sitio")
```

El uso de condicionales en nuestros proyectos de software nos ayudara a controlar el flujo de datos en nuestro programa, haciendo que nuestros sistemas se comporten conforme a las reglas que nosotros establezcamos desde el diseño.
