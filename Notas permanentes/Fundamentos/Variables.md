### ¿Que son las variables?
Las variables en programación son espacios en memoria que nombramos según lo que estos representen en el contexto de nuestro programa.

### Declaración de variables en varios lenguajes de programación
```javascript
//Javascript
var numero = 10
let numero = 10
const PI = 3.1416 
```

```python
# Python
numero = 10
```

### Buenas practicas al nombrar variables
Las variables deben ser autodescriptivas, no debería ser necesario añadir un comentario describiendo el significado de la variable.

```python
# Convenciones de nombrado para los booleanos, usar prefijos como is, are o has
isVisible = true
areEqual = false
hasEncryption = true

# Convenciones de nombrado para Funciones, usar camelCase
def getName():
	print("Hola me llamo pablo")
	
# Convenciones para clases, usar Pascal Case
class SoftwareDeveloper

# Convencion para metodos privados en una clase, colocar un _ antes del nombre
_getName()

# Convencion para valores constantes
SEGUNDOS = 60
MINUTOS = 60
HORAS = 24
NOMBRE_COMPLETO = "Luis Pablo Mujica vargas"

```
